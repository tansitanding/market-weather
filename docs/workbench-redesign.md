首页顺序为主要指数、投资建议、行情冷暖和依据、行业与全球资料。建议利用沪深300与20日均线、同日上涨广度和持续强势行业，给出防守观察、等待确认或分批验证。行业证据标注自己的日期；数据跨日不作为同日共振证据。系统选股保留已有的量价与流动性限制，建议阈值仍需回测验证。

GitHub Pages 是静态托管，触发 Actions 需要有仓库写权限的身份。页面仅保留一个刷新入口，转到 GitHub 运行任务，返回页面后自动检查新版本。直接在页面内提交任务需要带身份验证及限频的后端。手填记录保存在本机浏览器，不依赖这一后台。
