本地预览

在仓库根目录执行 npm ci，然后执行 npm run dev，打开 http://127.0.0.1:5173/。只有本机开发 / 预览服务会读取 .local/data/latest.json，没有将行情数据复制到 public 或 dist。

首次克隆仓库需先按 README 执行采集，或提供有效的本地快照；没有数据时页面会显示空状态。生产构建可以用 npm run build 验证，正式公网数据导出仍默认关闭。

另已生成本地离线评审文件，内含固定采集快照，未上传公开仓库。脚本语法已检查；浏览工具不允许打开 file 协议，因此直接打开该文件的渲染效果尚未自动验证。上文浏览器验收均基于本机服务版本。

当前数据限制

行业数据截至 2026-11-19，A 股日线截至 2026-11-20。申万源缺少 2026-10-15、2026-11-10，区间起止收益可算，但完整路径的回撤、热度与升温不可计算。页面显式说明，不自动补零或平滑连接。国际数据按各市场自己的观测时间标注。
