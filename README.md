# 股市气象站 Market Weather

手机优先的公开市场研究工作台。访问地址：**https://tansitanding.github.io/market-weather/**。阅读无需账号，页面始终呈现最新有效资料，不按采集时点分 tab。

## 已实现

- 总览：优先展示我的观察计划、到期复查、行业榜单变化和大盘检查点；指数、市场冷暖和资讯可按需展开。
- 建议：独立标签页汇总大盘、行业、关注个股、关注基金和债券。
- 行业：申万 2021 一级行业 31 类，最近 30 个交易日逐日涨幅 Top 10。可按日期切换，查看涨跌条形图、上榜次数和行业详情的逐日涨跌。
- 全球：美股、港股、美元、美债收益率、金油连续期货，独立时区和观测时间；美港股冷暖与样本覆盖，美港联动、科技相对强弱、美元和利率、商品分析。
- 债券晴雨表：5 年期国债 ETF 市价与美国 10 年期国债收益率，标明各自观测日和变动单位。
- 跟踪：可从行业详情或个股研究卡加入私人观察，记录确认条件、失效条件和复查日期，或手工记录交易。个人记录保存在当前浏览器，可导出和合并导入 JSON，也可导出 Markdown。系统个股候选与 5/10/20 日纸面跟踪另行呈现。
- 采集：GitHub Actions 在北京时间交易日 08:45 / 11:45 / 17:30 运行，GitHub 调度可能延迟。未知年份日历会降级，不伪造交易日。
- 手动更新：页面的“刷新数据”会在当前页检查并载入最新已发布快照。后台采集按计划运行。
- 资讯优先展示近 7 天的政策、经济数据和市场事件，注明关注原因。相近时间的同链接或高度相似标题会合并，保留相关来源。可切换全部资讯，按发布时间阅读。
- 来源失败隔离、最近有效数据保留、重试、去重、时间校验、本机缓存及新资料提示。

这是确定性规则研究，未接入生成式AI，不承诺收益，也不执行交易。市场温度不是上涨概率；纸面记录不是用户成交。

## 当前数据限制

行业日涨幅比较相邻两个交易日的收盘。任一日缺失时，对应日涨幅留空，部分覆盖的榜单会注明可计算行业数。上榜次数统计采用完整榜单。行业建议可使用部分覆盖日，标为初步观察；已有连续强势且当天完整的行业可列为优先观察。

仅发布必要观测、衍生指标、新闻标题与原文链接。原始行情响应保存在忽略的 `.local/`，不上传为完整原始数据镜像；`state` 分支保存公开简报与纸面研究状态。来源可用性和再分发权是不同问题，后者未声称已获供应商授权。

## 运行与验证

Python 3.9+、Node.js 24+；Python仅使用标准库。

```sh
npm ci
PYTHONPATH=src python3 scripts/release.py
npm run dev
```

访问 http://127.0.0.1:5173/。开发服务只读本机有效快照；无数据时明确展示空状态。公开构建由发布流程单独复制经过裁剪的 `.release/latest.json` 到 `dist/data/`。

```sh
npm run test:data
npm run test:web
npm run build
```

37项Python测试、27项前端测试覆盖缺日与同日终对齐、规则过滤、T+1纸面退出、跳空取消、复权变更、成本、资料裁剪、类型校验与缓存异常。真实数据与手机浏览器另行验证。

## 研究口径

温度：上涨广度30%、沪深300相对20日均线30%、成交额相对前20日均值25%、波动风险15%；完整日终评估。盘前与午间沿用最近已确认日终，并更新可用资讯。

行业观察按最近可用日期的上涨行业筛选，最多列三个。优先观察要求当日行业覆盖完整，且近五个交易日至少三次在完整榜单中上涨上榜。其余证据降为初步观察。个股只在这些行业成交额靠前的有限成分池中筛选，不代表全市场扫描。规则细节见 `src/market_weather/analysis.py`。

纸面跟踪保留原始信号：完整收盘确认、次日开盘模型入场、偏离超过3%取消、T+1之后按1.5ATR风险线模拟；5/10/20交易日净收益扣0.1%往返成本。未模拟全部滑点、涨跌停排队和券商费用差异；复权基准变化停止统计。无真实信号时记录为空。
