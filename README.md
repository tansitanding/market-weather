# 股市气象站 Market Weather

手机优先的公开市场研究工作台。前台统一呈现最新有效内容；北京时间 08:45、11:45、17:30 只作为后台采集计划。阅读不要求登录，所有者触发采集的权限单独管理。

项目处于开发孵化阶段，尚未发布正式网站，也未启用定时采集或投资推荐。

## 当前交付

- 手机原型：总览、行业排行、行业详情、全球与宏观、个股观察。
- 分类与口径：申万 2021 一级行业；30 个交易间隔收益；交易热度与涨幅分别计算。
- Python 数据程序：有界重试、日历与时区、新闻标题去重、历史快照、原子发布、离线重放。
- TypeScript / Vite 四模块手机页面、行业详情与快照类型校验，第四阶段已完成本地实现。
- 21 项核心测试通过；真实采集取得 31 个行业、9 项国际行情观测、55 条近 30 日新闻；四模块离线重放一致。

**真实数据限制：**2026-11-20 的验证发现申万行业历史缺少 2026-10-15、2026-11-10。区间起止数据完整，30 日收益可以计算；完整路径最大回撤、30 日交易热度和升温榜因此暂停输出，数据不补造。行业截至 11-19，与 A 股最新日线 11-20 分别标注。

## 本地运行

环境：Python 3.9+、Node.js 24+。Python 程序仅使用标准库。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/` 可预览第四阶段的实际页面。开发服务只读本机 `.local/data/latest.json`，不会触发采集；克隆后需先采集，没有快照时展示空状态。原始设计原型仍可另行预览：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory docs
```

打开 `http://127.0.0.1:8768/prototype/index.html`。

在仓库根目录执行一次真实采集：

```sh
PYTHONPATH=src python3 -m market_weather.pipeline --root .local/data
```

行情、原始响应和新闻元数据仅保存在被 Git 忽略的 `.local/`。公开接口连通不代表取得公开再分发许可；公网导出默认关闭。未购买数据订阅，未启用真实交易。

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 scripts/check_replay.py
npm run test:web
npm run build
```

离线重放依赖本机已留存的原始响应与上一次快照，克隆仓库后需先完成采集。它不会联网，也不会用演示数据替代真实数据。

## 开发阶段

1. 产品设计与行业原型：已完成开发基线。
2. 独立仓库、项目骨架、来源可用性验证：已落地；市场数据再分发许可仍待确认。
3. 采集与指标程序：已实现并实测；热度真实输出受源数据缺日影响，待可靠备源补齐。
4. 四模块手机页面：10 项开发与验收已完成，23 项前端测试通过，手机三种宽度和异常场景已实测，见验收报告。

6. 定时任务、管理身份验证、正式域名发布：未启用。

普通阅读始终无需登录；现阶段不将采集管理权限暴露给匿名访客。日历只确认了 2026 年，未知年份显式报错，不能默认周一至周五为交易日。
